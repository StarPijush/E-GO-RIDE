`9000000001` / `EgoDemo@123`. Registration OTP: `123456`.

Run with `--dart-define=AUTH_MODE=mock`. See
[`docs/ego_mock_auth_testing_guide.md`](docs/ego_mock_auth_testing_guide.md)
